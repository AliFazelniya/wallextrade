## 3. Recommended Technical Settings & Generation Parameters

| Parameter | Recommended Value | Rationale |
| :--- | :--- | :--- |
| **Aspect Ratio** | `16:9` (1920x1080 or 3840x2160) | Standard presentation and YouTube pitch format |
| **Frame Rate** | `60 fps` (or `30 fps` with optical flow) | High-frequency trading tech feels smoother at high framerates |
| **Color Space** | Rec.709 / Teal & Emerald FinTech | Institutional trust, high contrast dark theme |
| **Motion Strength** | `5` to `7` (Medium-High) | Dynamic data flows without unnatural warping |
| **Seed / Consistency** | Fixed seed for scenes 2 & 5 | Ensures dashboard and aesthetic consistency |
