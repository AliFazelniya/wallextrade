# گزارش تست در سایه با داده‌های زنده صرافی والکس (Shadow Test Report)

این گزارش عملکرد سامانه معاملاتی را در حالت تست در سایه (Shadow Mode) بر روی داده‌های زنده و عمق واقعی بازار والکس بدون ارسال سفارش حقیقی مستند می‌کند.

## ۱. مشخصات محیط تست
- **حالت اجرا:** SHADOW (بدون ارسال سفارش به سرور لایو، ثبت شبیه‌سازی منطبق بر اردر بوک زنده)
- **تعداد چرخه‌های اجراشده:** 3
- **سرمایه اولیه اسمی:** ۵،۰۰۰،۰۰۰ تومان
- **فایل لاگ حسابرسی تصمیمیات:** `logs/trading_decisions.jsonl`
