# سامانه معاملاتی الگوریتمی عامل‌محور والکس (Wallex Agentic AI Trading System)
### رویداد هکاتون هوش مصنوعی استارکوچ × صرافی والکس (Starcoach × Wallex Hackathon)

این مخزن شامل پیاده‌سازی کامل، بازتولیدپذیر، کمّی و امن یک سیستم معاملاتی الگوریتمی مستقل برای رویداد ۳ روزه هکاتون مشترک **استارکوچ و صرافی والکس** است.

---

## ۱. ویژگی‌های کلیدی سامانه (Key Features)

- **ارتباط زنده با صرافی والکس:** دریافت مستقیم عمق دفتر سفارش (`/v1/depth`)، معاملات لحظه‌ای (`/v1/trades`) و داده‌های تاریخی استاندارد UDF تریدینگ‌ویو (`/v1/udf/history`).
- **نقش ساختاریافته هوش مصنوعی عامل‌محور (Agentic AI):** تحلیل وضعیت کلان بازار و طبقه‌بندی هوشمند رژیم قیمتی (`MarketRegime`) با مدل داده معتبر Pydantic و سیستم جایگزین قطعی (Deterministic Fallback).
- **موتور ریسک مستقل با اختیار وتوی کامل (Independent Risk Engine):** اعمال قطعی سقف سفارش ۵۰۰،۰۰۰ تومان، سقف تعهد ۶۰٪ پورتفولیو، حد ضرر ۲٪ و حد سود ۳.۵٪، و توقف اضطراری در دراوداون ۵٪.
- **تضمین تسویه به تومان (Toman Liquidation Protocol):** نقد کردن خودکار ۱۰۰٪ دارایی‌های سبد به تومان (TMN) در انتهای دوره مسابقه مطابق بند ۱۰ اهداف.
- **دفتر ثبت رویداد و ردپای حسابرسی (Audit Trail):** ثبت کلیه تصمیمات، مشاهدات بازار و استدلال‌های ایجنت در قالب فایل ساختاریافته `logs/trading_decisions.jsonl`.
- **آزمایش‌پذیری و بازتولیدپذیری کامل:** پوشش تست‌های واحد خودکار با Pytest و اجرای بک‌تست تاریخی و تست در سایه با یک دستور.

## ۴. راهنمای اجرای سریع (Quick Start)

### گام ۱: آماده‌سازی محیط
```bash
cd /root/starcoach-hack/wallex
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
pip install pytest pytest-asyncio
cp .env.example .env
```

### گام ۲: اجرای آزمون‌های سلامت سیستم
```bash
pytest tests/ -v
```

### گام ۳: اجرای بک‌تست تاریخی
```bash
python scripts/run_backtest.py BTCTMN ETHTMN
```

### گام ۴: اجرای تست در سایه (Shadow Mode)
```bash
python scripts/run_shadow.py
```

## ۵. امنیت و فعال‌سازی معاملات لایو (Live Trading Safety)

- **پیش‌فرض امن:** معاملات لایو به صورت پیش‌فرض در کد مسدود است (`TRADING_MODE=SIMULATION`).
- **شرط فعال‌سازی لایو:** حتی در صورت تنظیم `TRADING_MODE=LIVE` در فایل `.env`، معامله تنها زمانی امکان‌پذیر است که پرچم تایید مستقیم انسانی (`live_execution_authorized=True`) توسط کاربر به سیستم داده شود.
- **محرمانگی اطلاعات:** هیچ کلید دسترسی یا اطلاعات حساسی در کدهای منبع وجود ندارد و همه از طریق محیط امن لود می‌شوند.
